# Быстрый старт

## Авторизация в приложении

После исправления проблемы с авторизацией, приложение теперь использует **правильный метод** согласно официальной документации API.

### ⚠️ Важное изменение

Теперь авторизация происходит через **Telegram бота** с использованием QR-кода, а не через простой ввод username.

## Как авторизоваться

### Способ 1: Через Telegram бота (Рекомендуемый)

1. **Запустите приложение**
   - Откроется экран с QR-кодом

2. **Откройте Telegram**
   - Найдите бота: `@interesnoitochka_bot`
   - Или перейдите по ссылке: https://t.me/interesnoitochka_bot

3. **Отсканируйте QR-код**
   - Используйте камеру телефона или функцию сканирования в Telegram
   - QR-код содержит ссылку для авторизации

4. **Подтвердите вход в боте**
   - Следуйте инструкциям бота
   - Подтвердите авторизацию

5. **Автоматический вход**
   - Приложение автоматически получит токены через WebSocket
   - Вы будете перенаправлены к списку чатов

### Способ 2: Ручной ввод токенов (Для тестирования)

Если у вас уже есть токены:

1. **На экране авторизации нажмите**
   - "Ввести токен вручную" (внизу экрана)

2. **Введите токены**
   - Access Token
   - Refresh Token

3. **Нажмите "Войти"**
   - Вы будете перенаправлены к списку чатов

## Получение токенов для тестирования

Если вам нужны токены для ручного ввода:

1. Авторизуйтесь в веб-версии или другом приложении
2. Извлеките `access_token` и `refresh_token` из DevTools или настроек
3. Используйте их в приложении через "Ввести токен вручную"

## Что происходит под капотом

```
1. Создание сессии → 2. Генерация QR → 3. WebSocket ожидание
                              ↓
4. Сканирование в боте → 5. Получение токенов → 6. Вход в чаты
```

## Troubleshooting

### Проблема: QR-код не генерируется
**Решение**: Проверьте интернет соединение и перезапустите приложение

### Проблема: Отсканировал QR, но ничего не происходит
**Решение**:
- Убедитесь что WebSocket подключен (статус "Отсканируйте QR-код в боте")
- Проверьте что вы используете правильного бота @interesnoitochka_bot
- Подтвердите авторизацию в боте

### Проблема: Нет доступа к Telegram
**Решение**: Используйте "Ввести токен вручную" с существующими токенами

### Проблема: Ошибка "Field required" при старом методе
**Решение**: Старый метод авторизации по username больше не поддерживается. Используйте новый метод через QR-код.
