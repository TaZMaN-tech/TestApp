# TestApp - iOS Chat Application

Тестовое задание для платформы "Интересно и точка"

## Описание

iOS приложение с 3 экранами:
1. **Авторизация** - экран входа по username
2. **Список чатов** - экран со списком всех чатов пользователя
3. **Сообщения в чате** - экран с сообщениями и WebSocket для получения новых сообщений в реальном времени

## Технологии

- UIKit (programmatic UI, без Storyboards)
- URLSession для API запросов
- WebSocket для real-time сообщений
- Swift Concurrency (async/await)
- MVC архитектура

## Функциональность

### 1. Экран авторизации
- QR-код для авторизации через Telegram бота (@interesnoitochka_bot)
- WebSocket подключение для получения токенов
- Альтернативный метод: ручной ввод токенов
- Автоматическое сохранение токенов
- Автоматический переход к списку чатов при успешной авторизации

### 2. Список чатов
- Отображение всех чатов пользователя
- Поиск по чатам
- Функция поиска пользователя по username (кнопка с лупой)
- Индикатор онлайн статуса
- Количество непрочитанных сообщений
- Кнопка выхода

### 3. Экран сообщений
- Отображение истории сообщений
- Отправка текстовых сообщений
- Получение новых сообщений через WebSocket в реальном времени
- Автоматическая пометка сообщений как прочитанных
- Поддержка клавиатуры

## API

Приложение использует API платформы interesnoitochka.ru:
- **Base URL**: `https://interesnoitochka.ru/api/v1`
- **WebSocket**: `wss://interesnoitochka.ru/connection/websocket`

### Основные endpoints:
- `POST /auth/jwt/access/new` - авторизация
- `GET /chats` - получение списка чатов
- `GET /chats/{chat_id}/messages` - получение сообщений чата
- `POST /chats/messages` - отправка сообщения
- `GET /chats/{chat_id}/subscribe` - получение токена для WebSocket

## Как использовать

### 1. Запуск
1. Откройте `TestApp.xcodeproj` в Xcode
2. Выберите симулятор или устройство
3. Нажмите Run (⌘R)

### 2. Авторизация
**Вариант 1 (Основной): Через Telegram бота**
1. Откроется экран с QR-кодом
2. Отсканируйте QR-код в Telegram боте @interesnoitochka_bot
3. Подтвердите авторизацию в боте
4. Токены будут получены автоматически

**Вариант 2 (Альтернативный): Ручной ввод токенов**
1. Нажмите "Ввести токен вручную"
2. Вставьте `access_token` и `refresh_token`
3. Нажмите "Войти"

### 3. Поиск пользователя natfullin
После авторизации:
1. На экране "Чаты" нажмите на кнопку с лупой (🔍) в правом верхнем углу
2. В появившемся диалоге уже предзаполнено `2/natfullin`
3. Нажмите "Найти"
4. Откроется чат с пользователем
5. Напишите произвольное сообщение
6. Ответное сообщение придет автоматически через WebSocket
