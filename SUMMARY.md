## Как протестировать задание

### Пошаговая инструкция:

1. **Открыть проект**
   ```bash
   open TestApp.xcodeproj
   ```

2. **Запустить на симуляторе**
   - Выбрать любой iPhone симулятор
   - Нажать Run (⌘R)

3. **Авторизоваться**
   - Ввести любой username (например: `testuser`)
   - Нажать "Войти"

4. **Найти пользователя 2/natfullin**
   - На экране "Чаты" нажать кнопку с лупой (🔍) в правом верхнем углу
   - В появившемся диалоге уже предзаполнено: `2/natfullin`
   - Нажать "Найти"

5. **Отправить сообщение**
   - Откроется чат с пользователем
   - Ввести произвольное сообщение в поле внизу
   - Нажать синюю кнопку отправки (➡️)

6. **Получить ответ**
   - Ответное сообщение придет автоматически через WebSocket
   - Вы увидите его в реальном времени без перезагрузки
   - Сообщение появится слева с серым фоном

## Технические детали

### Технологии
- **UIKit**: Весь UI создан программно (без Storyboards)
- **URLSession**: Для REST API запросов
- **WebSocket**: Для получения сообщений в реальном времени
- **Swift async/await**: Современный асинхронный код
- **MVC**: Архитектурный паттерн

### API интеграция
Полная интеграция с API платформы interesnoitochka.ru:
- ✅ Авторизация (`POST /auth/jwt/access/new`)
- ✅ Получение чатов (`GET /chats`)
- ✅ Получение сообщений (`GET /chats/{id}/messages`)
- ✅ Отправка сообщений (`POST /chats/messages`)
- ✅ WebSocket подписка (`GET /chats/{id}/subscribe`)
- ✅ WebSocket соединение (`wss://interesnoitochka.ru/connection/websocket`)

### Структура кода
```
TestApp/
├── Models/          - Модели данных (User, Chat, Message)
├── Services/        - Сервисы (API, Auth, WebSocket)
├── ViewControllers/ - 3 экрана (Auth, Chats, Chat)
├── Views/           - Кастомные ячейки
└── Helpers/         - Вспомогательные функции
```

**Статистика:**
