# Инструкция по использованию TestApp

## Быстрый старт

### 1. Запуск приложения

```bash
# Откройте проект в Xcode
open TestApp.xcodeproj

# Или через командную строку
xcodebuild -project TestApp.xcodeproj -scheme TestApp -configuration Debug
```

### 2. Первый запуск - Авторизация

При первом запуске вы увидите экран авторизации:

1. Введите username (например: `testuser` или любое другое имя)
2. Нажмите кнопку "Войти"
3. После успешной авторизации вы автоматически перейдете к списку чатов

**Примечание**: Токен сохраняется автоматически, при следующем запуске вы сразу попадете в список чатов.

### 3. Работа со списком чатов

На экране "Чаты" доступны следующие функции:

#### Основные функции:
- **Список чатов**: Отображаются все ваши чаты с последним сообщением
- **Поиск**: Используйте строку поиска для фильтрации чатов
- **Поиск пользователя**: Кнопка с лупой (🔍) в правом верхнем углу
- **Выход**: Кнопка "Выйти" для выхода из аккаунта

#### Индикаторы в списке чатов:
- 🟢 Зеленая точка - пользователь онлайн
- 🔵 Синий бейдж - количество непрочитанных сообщений
- ⏰ Время последнего сообщения (сегодня - HH:mm, вчера - "Вчера", раньше - DD.MM.YY)

### 4. Поиск пользователя 2/natfullin (Тестовое задание)

Для выполнения тестового задания:

1. На экране "Чаты" нажмите кнопку с лупой (🔍)
2. В диалоговом окне уже будет предзаполнено: `2/natfullin`
3. Нажмите "Найти"
4. Если чат уже существует - откроется сразу
5. Если чата нет - будет автоматически отправлено приветственное сообщение и создан чат
6. Откроется экран чата с пользователем

### 5. Отправка сообщений

В экране чата:

1. Введите текст сообщения в поле внизу экрана
2. Нажмите синюю кнопку со стрелкой (➡️)
3. Сообщение отправится и появится справа (синий фон)
4. Входящие сообщения появятся слева (серый фон)

### 6. Получение ответа через WebSocket

После отправки сообщения пользователю `2/natfullin`:

1. Ответное сообщение придет автоматически
2. Вы увидите его в реальном времени без перезагрузки
3. Сообщение появится с серым фоном слева
4. Автоматически будет помечено как прочитанное

## Детальное описание экранов

### Экран 1: Авторизация (AuthViewController)

**Элементы UI:**
- Логотип "Интересно и точка"
- Подзаголовок "Войдите чтобы продолжить"
- Поле ввода username
- Кнопка "Войти"
- Индикатор загрузки

**Функциональность:**
- Валидация ввода (кнопка активна только при заполненном поле)
- Автоматическое сохранение токена в UserDefaults
- Обработка ошибок с понятными сообщениями
- Автоматический переход к чатам при успешной авторизации

**API:**
```
POST /auth/jwt/access/new?username={username}
Response: { user: {...}, tokens: { access_token, refresh_token } }
```

### Экран 2: Список чатов (ChatsViewController)

**Элементы UI:**
- Navigation bar с заголовком "Чаты"
- Поисковая строка
- Список чатов (UITableView)
- Кнопки: Выйти, Поиск пользователя

**Каждая ячейка чата содержит:**
- Аватар пользователя (или иконка по умолчанию)
- Имя пользователя / чата
- Последнее сообщение
- Время последнего сообщения
- Бейдж с количеством непрочитанных
- Индикатор онлайн статуса

**Функциональность:**
- Загрузка всех чатов при открытии
- Локальный поиск по имени чата
- Поиск пользователя по username с автоматическим созданием чата
- Pull-to-refresh (можно добавить)

**API:**
```
GET /chats?offset=0&limit=100
Response: { chats: [...], total, offset, limit }
```

### Экран 3: Сообщения (ChatViewController)

**Элементы UI:**
- Navigation bar с именем собеседника
- Список сообщений (перевернутый UITableView)
- Поле ввода сообщения
- Кнопка отправки

**Каждая ячейка сообщения содержит:**
- Текст сообщения
- Время отправки
- Цветной фон (синий - исходящие, серый - входящие)
- Выравнивание (справа - исходящие, слева - входящие)

**Функциональность:**
- Загрузка истории сообщений
- Отправка текстовых сообщений
- **WebSocket для получения новых сообщений в реальном времени**
- Автоматическая прокрутка к новым сообщениям
- Автоматическая пометка как прочитанных
- Поддержка клавиатуры с автоматическим сдвигом

**API:**
```
GET /chats/{chat_id}/messages?offset=0&limit=50
POST /chats/messages
  Body: { recipient_id or username, message_type: "text", content }
GET /chats/{chat_id}/subscribe
  Response: { token, channel, expires_at }
```

**WebSocket:**
```
WSS wss://interesnoitochka.ru/connection/websocket
Connect: { "connect": { "token": "...", "name": "swift" } }
Subscribe: { "subscribe": { "channel": "chat_123" } }
Receive: { "push": { "data": { "message": {...} } } }
```

## Архитектура

### MVC Pattern

```
Models/
├── User.swift       - Модель пользователя
├── Chat.swift       - Модель чата
└── Message.swift    - Модель сообщения

Services/
├── AuthManager.swift      - Управление токенами (Singleton)
├── APIService.swift       - REST API клиент (Singleton)
└── WebSocketService.swift - WebSocket клиент (Singleton)

ViewControllers/
├── AuthViewController.swift  - Экран авторизации
├── ChatsViewController.swift - Список чатов
└── ChatViewController.swift  - Экран сообщений

Views/
├── ChatTableViewCell.swift    - Ячейка чата
└── MessageTableViewCell.swift - Ячейка сообщения
```

### Data Flow

1. **Авторизация:**
   ```
   User Input → AuthViewController → APIService → AuthManager → ChatsViewController
   ```

2. **Загрузка чатов:**
   ```
   ChatsViewController → APIService → Server → Update UI
   ```

3. **Отправка сообщения:**
   ```
   ChatViewController → APIService → Server → UI Update
   ```

4. **Получение сообщения через WebSocket:**
   ```
   Server → WebSocketService → Delegate → ChatViewController → UI Update
   ```

## Обработка ошибок

Приложение обрабатывает следующие типы ошибок:

1. **Сетевые ошибки**: Нет интернета, таймаут
2. **API ошибки**: 401 (Unauthorized), 404 (Not Found), 500 (Server Error)
3. **Ошибки валидации**: Пустое поле ввода
4. **WebSocket ошибки**: Потеря соединения, ошибки подключения

Для каждой ошибки показывается Alert с понятным сообщением и возможностью повтора.

## Известные ограничения

1. **Токены в UserDefaults**: Для production следует использовать Keychain
2. **Только текстовые сообщения**: Медиа не поддерживаются
3. **Нет оффлайн режима**: Требуется постоянное интернет соединение
4. **Нет пагинации**: Загружаются все сообщения/чаты сразу (limit 100)
5. **WebSocket reconnect**: Базовая реализация без advanced retry logic

## Troubleshooting

### Проблема: Не удается авторизоваться
**Решение**: Проверьте интернет соединение и попробуйте другой username

### Проблема: Чаты не загружаются
**Решение**: Нажмите "Повторить" в алерте или перезапустите приложение

### Проблема: Сообщения не приходят в реальном времени
**Решение**: Проверьте что WebSocket подключен (консоль Xcode покажет "WebSocket connected")

### Проблема: Приложение вылетает
**Решение**: Проверьте консоль Xcode на наличие ошибок, убедитесь что API доступен
